# 官方来源与搜索路径

以下入口已于 2026-09-08 核验。交易所前端可能变化，因此应优先依据页面标签和结构操作，不要依赖未公开的请求参数。

## 深圳证券交易所（深交所）

- 官方域名：`https://www.szse.cn/`
- 上市公司公告：`https://www.szse.cn/disclosure/listed/notice/index.html`
- 页面提供 `代码/简称/拼音/标题关键字`、公告类别和日期范围。已知股票代码时使用准确代码搜索；否则使用发行人简称，并在结果中确认股票代码。
- 使用标题关键字 `年度报告` 搜索目标财政年度。日期范围应覆盖页面默认范围之外；财政年度 Y 的年报通常在 Y+1 年发布。
- 优先选择标题明确表示完整年报或完整修订版的结果。排除 `年度报告摘要` 及仅提到年报的其他公告。

## 上海证券交易所（上交所）

- 官方域名：`https://www.sse.com.cn/`
- 上市公司公告：`https://www.sse.com.cn/disclosure/listedinfo/announcement/`
- 页面提供 `6位代码 / 简称`、`标题 / 关键字`、公告类型和日期筛选。优先使用股票代码，避免混淆名称相近的发行人。
- 搜索 `年度报告` 和对应公告期间。如果没有结果，先重置限制性较强的公告类型条件，再扩大日期范围。
- 结合公告所示发行人名称、股票代码和年报封面确认发行人身份。

## 北京证券交易所（北交所）

- 用户指定的官方域名：`https://www.bseinfo.net/`
- 上市公司公告：`https://www.bseinfo.net/disclosure/announcement.html`
- 页面提供 `公司简称/拼音/代码`、`关键字` 和 `日期`。默认只展示最近一个月公告，因此搜索年报时必须明确扩大日期范围。
- 使用 `年度报告` 作为关键字，并优先采用股票代码完全匹配的结果。页面可能包含 iframe；如果顶层页面自动化无法操作目标控件，应直接进入 iframe 地址，或使用顶层页面可见的筛选字段。

## 香港交易及结算所有限公司（港交所）

- 集团官网：`https://www.hkex.com.hk/`
- 官方发行人文件搜索（披露易／HKEXnews）：`https://www1.hkexnews.hk/search/titlesearch.xhtml?lang=zh`
- 在 `現有上市證券` 中按股票代码或发行人名称搜索。页面提供 `股份代號/股份名稱`、标题及文件类别、开始/结束日期和消息标题关键字。
- 扩大默认一个月的日期范围。搜索财政年度 Y 时，先从 Y+1 年的公告期开始；发行人的财政年度不是自然年，或存在较晚修订公告时，应进一步扩大范围。
- 优先选择官方 `年報`、`年度報告` 或 `Annual Report` 文件类别。不得用年度业绩公告、通函、ESG 报告或月报表代替。
- 股票代码可能带前导零。元数据和文件名中应保留官方展示格式。

## 公司投资者关系网站

只有在交易所渠道失败、发行人并非交易所上市公司，或用户要求公司官网版本时，才使用该渠道。

1. 确认域名确实属于目标公司。强证据包括：官方交易所发行人资料中的链接、与公司法人主体一致的页面底部备案信息，或官方公告中明确列出的域名。
2. 搜索 `投资者关系`、`信息披露`、`定期报告`、`财务报告`、`Investor Relations`、`Financial Reports` 或 `Annual Reports` 栏目。
3. 确认文件托管于已核验的公司域名，或公司公开使用的静态资源/CDN 域名。搜索引擎摘要本身不能证明文件来源。
4. 使用与交易所文件相同的完整年报、财政年度、修订版本和 PDF 内容校验规则。

## 浏览器操作与下载回退

- 动态结果列表：填写筛选字段并触发可见的查询/搜索控件后，等待列表加载完成。
- 打开阅读器而非文件直链：检查链接的 `href`、页面内嵌 PDF 地址或对应网络响应。最终地址必须由官方网站托管。
- 依赖会话的链接：通过当前浏览器会话下载，再核验保存的文件。除非用户明确授权某个确需导出会话信息的流程，否则不得导出会话 Cookie。
- 验证码或限流：停止自动重试，保留已尝试的网址和筛选条件，请用户完成验证或稍后重试。
