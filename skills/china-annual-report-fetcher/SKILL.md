# 国内公司年度报告获取

返回经过核验的年度报告 PDF 文件，并提供足够的来源信息，让用户能够复核每一项结果。

## 理解用户需求

- 接受公司全称、简称、中英文名称或股票代码。证据明确时，自动判断上市地点。
- 年报标题或封面中的年份是财政年度（报告期年度），不要把次年的公告发布日期误当成报告年度。
- 用户未指定年份时，获取截至搜索日可取得的最新完整年度报告。用户要求“历年”或“全部”时，从官方来源获取所有可用年度。
- 优先使用用户指定的语言。用户未指定时，内地上市公司优先中文版；港股优先发行人发布的中文版；只有英文版时再使用英文版。
- 同一公司存在多个上市地时，优先采用名称或代码明确指向的上市地。只有在不同发行人或上市地确实无法区分，且选择会改变结果时，才提出一个简短问题。

## 搜索官方来源

搜索前阅读 [官方来源说明](references/official-sources.md)。动态披露页面应使用真实浏览器操作，优先依据控件的语义名称定位，不依赖易失效的 CSS 选择器。站内搜索或互联网搜索只用于发现官方结果，不能作为最终文件的权威来源。

按以下顺序搜索：

1. 已确认上市地对应的官方披露系统：深交所、上交所、北交所或港交所披露易（HKEXnews）。
2. 交易所结果不可用、不完整，或用户明确要求公司官网版本时，再搜索经过核验的公司投资者关系或财务报告页面。
3. 上市地未知时，先通过官方发行人资料或股票代码确定上市地，再搜索对应的披露系统。不要仅凭公司名称猜测。

不得从聚合网站、文档分享网站、搜索缓存或媒体文章下载文件。如果官方网站出现验证码或访问验证，并且现有浏览器操作无法完成，应停止自动重试并请求用户手动处理。

## 选择正确公告

按以下规则排列候选结果：

1. 发行人名称或股票代码完全匹配。
2. 财政年度与用户要求完全匹配。
3. 选择完整的 `年度报告`、`年报` 或 `Annual Report`，不要选择 `年度报告摘要`、业绩公告、独立审计报告、ESG 报告、季度报告、中期报告、股东大会材料或年报发布提示公告。
4. 同一财政年度存在官方发布的完整 `修订版` 或 `更正版` 时，以发布时间较晚的修订版本为准；文件名保留修订标记，并向用户说明所选版本。
5. 交易所和公司官网存在完全相同的文件时，优先使用交易所版本，避免重复下载。

应从公告标题确认财政年度，必要时核对 PDF 封面。仅凭公告发布日期不足以判断报告年度。

## 安全下载

- 用户未指定输出目录时，默认保存到当前工作区的 `annual-reports/<安全的公司名称>/`。
- 使用稳定文件名，例如 `<公司名称>_<股票代码>_<财政年度>_年度报告.pdf`。只有需要区分时才追加 `_修订版`、`_中文` 或 `_英文`。移除路径分隔符和文件系统不允许的字符。
- 从搜索结果链接提取官方 PDF 直链。如果网站打开的是阅读器，应检查链接目标或网络响应，不要把阅读器页面打印成 PDF。
- 对公开直链优先使用 `scripts/download_pdf.py`。目标网站需要来源页时传入 `--referer`。除非明确传入 `--overwrite`，脚本会拒绝覆盖现有文件。
- 只有官方网站要求会话状态或使用短时效链接时，才通过浏览器下载。不得在消息、日志、文件名或元数据中暴露 Cookie、授权请求头或私密令牌。
- 控制请求频率，不得绕过验证码、访问控制或网站限流。

示例：

```bash
python3 scripts/download_pdf.py \
  --url "官方_PDF_直链" \
  --output "annual-reports/公司名/公司名_000001_2025_年度报告.pdf" \
  --referer "官方搜索结果页"
```

## 核验每个文件

不能仅因下载完成就宣告成功。

- 必须确认请求成功、响应内容非空且具有 PDF 文件签名。拒绝被保存为 `.pdf` 的 HTML 页面、JSON 错误响应、登录页面和访问验证页面。
- 使用可用的 PDF 工具检查前几页，确认发行人名称或股票代码、`年度报告`/`年报`/`Annual Report` 字样以及目标财政年度。如果无法提取文字，应渲染并目视检查封面。
- 记录最终官方链接、来源网站、公告标题、发布日期、财政年度、文件大小和 SHA-256。下载脚本会以 JSON 输出最终链接、文件大小及 SHA-256 等文件信息。
- 即使文件具有 PDF 签名，如果页数或文件大小异常，也应视为可能选错候选并重新核查。

## 返回结果

为每个文件返回简明摘要，包括公司名称、股票代码、上市地（已知时）、财政年度、版本或语言、发布日期、官方来源链接，以及可点击的本地文件路径。如果回退到公司官网，应明确说明。

如果没有找到有效年报，应说明搜索过的官方来源和日期范围，只列出有参考价值的相近结果，并解释未采用的原因。不得悄悄改用非官方文件或年报摘要。
