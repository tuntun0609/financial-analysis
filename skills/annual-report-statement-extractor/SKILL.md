# 财务报表模板化提取

交付一个 `.xlsx` 文件、一个名为 `万元` 的工作表。工作表只保留财报合并报表科目和用户指定期间的数值，不附加原表名称、单位、来源、说明、占比、同比、公式或分析栏。

## 模板与科目来源

- 使用 [assets/财务报表-模板.xlsx](assets/财务报表-模板.xlsx) 的 `万元` 工作表作为**版式参考**：表头样式、边框、行高、列宽、数字格式、冻结窗格和合计行加粗等约定以模板为准。
- 输出**科目清单、数量和顺序不固定于模板**，而是跟随所提取财报合并报表的实际列示项目，按原表顺序排列；不强行映射到模板或特定会计准则（如内地 CAS）科目体系。
- 纳入三张主表的全部行项目：合并（简明）综合收益表／利润表、合并（简明）综合财务状况表／资产负债表、合并（简明）现金流量表。不纳入权益变动表、全面收益表、附注明细或每股盈利等非金额项目。
- 财报某一期间未列示的行，该期单元格保持空白；原表以横杠或“–”表示无金额的写为数值 `0`。
- 同一科目在流动与非流动等不同报表分区重复列示时，可加“（非流动）”“（流动）”等后缀区分，并在交付说明中注明。
- 报告间措辞差异（如“年度盈利”／“期内盈利”、“年初”／“期初”）统一为通用表述，并在交付说明中注明原表用词。
- 繁体报告的科目名称转为简体中文输出，术语一一对应。
- 不把报告原表的换行、附注列号、括号层级说明或编号变化带入输出。

## 报告选择

- 确定公司、所需期间及报告类型。用户要求半年度数据时必须使用完整半年度报告，不得以年度报告、季度报告或业绩公告替代。
- 优先使用用户提供或工作区已有的完整报告 PDF；核对封面、公司、报告期间、报告类型和页数。缺少报告时，调用 `$china-annual-report-fetcher` 下载并核验官方完整报告。
- 对年度数据，优先采用包含该年度数据的最新财政年度年报中的比较数；若有更正或修订版，采用最新完整版本。
- 对半年度数据，采用对应年度半年度报告的本期列。不得把上年末资产负债表数或上年同期利润、现金流量数误作目标半年度数。

## 数值处理

- 只从合并财务报表取数：资产及负债权益科目来自合并财务状况表／资产负债表，利润科目来自合并收益表／利润表，现金流量科目来自合并现金流量表。不要混入母公司报表或附注明细。
- 逐格读取原表数值、负号、括号和精度；保留原表的正负号列示方向（如 IFRS 报表的成本费用为负数）。扫描版或文字层错位时，渲染相关页并目视核对，不凭 OCR 猜值。
- 原表金额按人民币元列示时，除以 `10,000` 转为万元；按人民币百万元列示时，乘以 `100` 转为万元。将换算结果写成 Excel 数值并保留可还原原数的精度；单元格显示格式参照模板使用千位分隔、零位小数。
- 原表明确列有该科目但单元格为空或以横杠表示无金额时，写为数值 `0`，与模板约定一致。原表未列该科目时保持空白，不把“未披露”推断为零。
- 不使用公式换算，不把数字写成文本，不用零替代无法辨认的数据。

## 输出版式

- 新建单工作表文件，不复制参考文件中的其他工作表。
- 参照模板：表头加粗并居中；科目左对齐；数值右对齐；使用模板的边框、行高、列宽和数字格式。
- 所有合计类科目必须整行加粗，科目名称及各期间数值使用相同的加重字重，不得只加粗科目名称。合计类科目包括：
  - 名称含 `合计`、`总额` 或 `总计` 的科目；
  - 收益表／利润表主汇总项目：收入合计、毛利、经营盈利、除税前盈利、净利润／期内盈利；
  - 现金流量表汇总项目：经营、投资、筹资活动产生的现金流量净额，现金及现金等价物净增加额、期初余额和期末余额。
- 不添加标题行、来源区、脚注、图表、批注、筛选辅助列或隐藏数据。

## 核验与交付

- 核对输出科目与所提取财报合并报表的科目文字、数量和顺序一致（含统一措辞、区分后缀等整理项的说明），并确认列数严格等于“科目列 + 用户要求的期间数”。
- 按财报自身结构核对勾稽关系：资产总额与权益及负债总额（或负债和所有者权益总计）平衡；分部收入合计等于收入合计；非流动与流动小计加总正确；三类现金流量净额合计等于现金及现金等价物净增加额（原表单列汇兑损益时，核对含汇兑差额后的期初、期末衔接）。
- 检查全部合计类科目均已整行加粗，且非合计类明细行不因相邻样式被误加粗。
- 确认所有金额单元格为数值或空白，工作簿无公式和公式错误，且只有一个 `万元` 工作表。
- 在最终回复中提供可点击的 `.xlsx`，并在正文说明使用的官方报告、科目整理规则（统一措辞、后缀标注、繁简转换）及财报未列示的数据行。来源信息只写在回复中，不写入工作表。
