# 财务报表模板化提取

交付一个 `.xlsx` 文件、一个名为 `万元` 的工作表。工作表只保留模板科目和用户指定期间的数值，不附加原表名称、层级、单位、来源、说明、占比、同比、公式或分析栏。

## 模板

- 使用 [assets/财务报表-模板.xlsx](assets/财务报表-模板.xlsx) 的 `万元` 工作表作为唯一科目清单、行序和版式参考。
- 输出首行为表头：A 列为 `科目`，其后按时间顺序排列用户要求的期间。年度列使用四位年份；半年度列须明确标为 `YYYY半年度`，不得与全年混淆。
- 输出行只包含模板 `万元` 工作表 A 列现有科目，不新增原报表项目，不保留模板 `模板` 工作表中的“即期报表”“计算占比”“计算同比”等辅助列。
- 使用模板中的科目文字和顺序。不要把报告原表的换行、附注号、括号说明或编号变化带入输出。

## 报告选择

- 确定公司、所需期间及报告类型。用户要求半年度数据时必须使用完整半年度报告，不得以年度报告、季度报告或业绩公告替代。
- 优先使用用户提供或工作区已有的完整报告 PDF；核对封面、公司、报告期间、报告类型和页数。缺少报告时，调用 `$china-annual-report-fetcher` 下载并核验官方完整报告。
- 对年度数据，优先采用包含该年度数据的最新财政年度年报中的比较数；若有更正或修订版，采用最新完整版本。
- 对半年度数据，采用对应年度半年度报告的本期列。不得把上年末资产负债表数或上年同期利润、现金流量数误作目标半年度数。

## 科目映射

- 只从合并财务报表取数：资产及负债权益科目来自合并资产负债表，利润科目来自合并利润表，现金流量科目来自合并现金流量表。不要混入母公司报表或附注明细。
- 优先按模板科目与原表项目名称匹配；可消除换行、无意义空格及报表编号变化，但不得用数值相近作为匹配依据。
- 模板中的简化名称按对应主表合计项目映射。例如：
  - `负债和所有者权益总计` 对应原表的 `负债和所有者权益（或股东权益）总计`；
  - `五、净利润` 对应合并利润表的净利润主合计，即使报告中的序号或括号说明发生变化；
  - 现金流量表项目忽略原表前置序号，但必须匹配相同活动类别和合计含义。
- 找不到可靠对应项时保留空白，并在交付说明中列明科目、期间和 PDF 页码；不得猜测或改用其他科目。

## 数值处理

- 逐格读取原表数值、负号、括号和精度。扫描版或文字层错位时，渲染相关页并目视核对，不凭 OCR 猜值。
- 原表金额按人民币元列示时，除以 `10,000` 转为万元。将换算结果写成 Excel 数值并保留可还原原数的精度；单元格显示格式参照模板使用千位分隔、零位小数。
- 原表明确列有该科目但单元格为空或以横杠表示无金额时，写为数值 `0`，与模板约定一致。原表未列该科目时保持空白，不把“未披露”推断为零。
- 不使用公式换算，不把数字写成文本，不用零替代无法辨认的数据。

## 输出版式

- 新建单工作表文件，不复制参考文件中的其他工作表。
- 参照模板：表头加粗并居中；科目左对齐；数值右对齐；使用模板的边框、行高、列宽和数字格式。
- 所有合计类科目必须整行加粗，科目名称及各期间数值使用相同的加重字重，不得只加粗科目名称。合计类科目包括：
  - 名称含 `合计` 或 `总计` 的科目；
  - 利润表主合计项目：营业总收入、营业总成本、营业利润、利润总额、净利润；
  - 现金流量表汇总项目：经营、投资、筹资活动产生的现金流量净额，现金及现金等价物净增加额、期初余额和期末余额。
- 不添加标题行、来源区、脚注、图表、批注、筛选辅助列或隐藏数据。

## 核验与交付

- 核对输出科目与模板的文字、数量和顺序完全一致，并确认列数严格等于“科目列 + 用户要求的期间数”。
- 对每个期间核对资产总计与负债和所有者权益总计；抽查流动资产合计、负债合计、净利润和三类现金流量净额的正负号及万元换算。
- 检查全部合计类科目均已整行加粗，且非合计类明细行不因相邻样式被误加粗。
- 确认所有金额单元格为数值或空白，工作簿无公式和公式错误，且只有一个 `万元` 工作表。
- 在最终回复中提供可点击的 `.xlsx`，并在正文说明使用的官方报告及无法映射的数据缺口。来源信息只写在回复中，不写入工作表。
