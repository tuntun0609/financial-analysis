# 结构分析

结构分析解决“企业的钱是什么形态”的问题。通过分析资产、负债、收入和现金流的构成与配置，识别资金沉淀在哪里、资金从哪里来、企业靠什么赚钱，以及现金最终流向哪里。

## 分析框架

| 分析维度 | 核心问题 | 分析重点 |
| --- | --- | --- |
| 资产结构 | 资金沉淀在哪里 | 资金的沉淀形态与资源配置 |
| 负债结构 | 资金从哪里来 | 资金来源渠道 |
| 收入结构 | 企业靠什么赚钱 | 主业盈利能力 |
| 现金流结构 | 钱从哪里来、到哪里去 | 现金循环路径 |

## 资产结构

资产结构分析按以下顺序展开：

1. 分别计算流动资产和非流动资产占总资产的比例。
2. 判断企业资产结构是以流动资产为主，还是以非流动资产为主。
3. 分别计算各资产类科目占总资产的比例。
4. 识别流动资产的主要构成科目，并按占总资产的比例由高到低排列。
5. 识别非流动资产的主要构成科目，并按占总资产的比例由高到低排列。

## 结构与风险入口

结构决定风险分析的入口。当某类科目占比较高时，应进一步关注与其相关的经营或财务风险：

| 结构特征 | 重点关注 |
| --- | --- |
| 应收账款占比高 | 回款情况 |
| 存货占比高 | 存货周转 |
| 固定资产占比高 | 产能利用率 |
| 短期借款占比高 | 续贷压力 |
